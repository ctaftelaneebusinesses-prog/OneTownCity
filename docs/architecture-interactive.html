● OneTownCity Architecture Reference

System Architecture & SaaS Domain Model

Performance-first hyperlocal discovery & multi-tenant SaaS platform. Engineered with Next.js App Router (TypeScript), Rust Axum 0.7 + Tokio + SQLx 0.8, and PostgreSQL 16 Full-Text Search.

The 6 SaaS Domain Boundaries

Domain 01
Directory Hub

Unified listing catalog across 4 verticals (news, education, students, business) with PostgreSQL FTS, locality filtering, and category mapping.

Domain 02
Identity & RBAC

Role assignments (super_admin, city_admin, content_provider, tenant_owner, student). Header-based persona verification context.

Domain 03
Strict Tenancy

Organizations (education or business) with server-derived tenant_id via VerifiedTenantContext. Zero trusting of client-supplied tenant IDs.

Domain 04
Monetization Engine

SaaS subscription tiers (free, growth_business, edu_pro, campus_enterprise) with monthly lead quotas and clearly labeled sponsored flags.

Domain 05
Telemetry & Leads

Actionable admission requests, course fee enquiries, WhatsApp/call telemetry tracking, and dated student passes.

Domain 06
Governance & Trust

Verification states (not_verified, owner_claimed, details_reviewed), moderation queue (pending, approved, rejected), and user issue reports.

End-to-End System Request Flow

Core API Contract & Endpoints

Method Endpoint Domain Description & Access
GET /api/v1/listings Directory Public directory search across Nellore & Kuppam with FTS, category & locality filters.
GET /api/v1/listings/:slug Directory Full listing dossier with structured courses, admissions data, and facilities.
GET /api/v1/news News Verified civic updates, campus events, and infrastructure tracker.
GET /api/v1/students/opportunities Students Internships, scholarships, hackathons, and verified student hostels.
POST /api/v1/enquiries Engagement Submit direct course fee, admission, or business availability enquiry.
POST /api/v1/telemetry/click Engagement Track WhatsApp & phone call interaction telemetry for listings.
GET /api/v1/saas/dashboard Tenancy Tenant owner metrics: profile views, lead quotas, and WhatsApp interactions.
PATCH /api/v1/saas/leads/:id/status Engagement Tenant updates lead status (open vs responded).
GET /api/v1/admin/moderation Governance City admin moderation queue for pending listings and student opportunities.
POST /api/v1/admin/verify/listing/:id Governance Assign or revoke details_reviewed verification seal.
