1. NEVER use generic purple/indigo gradients, oversized full-width white search bars, or plain unstyled white boxes.
2. ALWAYS use exposed `1px solid #D8D3C8` architectural grid lines on a `#F4F2EE` warm limestone canvas, paired with `#111110` Obsidian Carbon ink and `#FF4F17` Signal Vermilion accents.
3. Pair `Instrument Serif` for editorial headlines, `Plus Jakarta Sans` for UI copy, and `JetBrains Mono` (`tabular-nums`) for all dates, coordinates, IDs, and telemetry.
4. Every interactive state MUST use `framer-motion` spring physics (`type: "spring", stiffness: 380, damping: 30`), shimmer loading skeletons during data fetches, and `sonner` toast feedback.
5. Strictly ZERO emojis anywhere in the DOM. Use crisp 1.5px stroke `lucide-react` icons and custom SVG geometric patterns.
